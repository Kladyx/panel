Původ

Začalo to jednoduše.

Chtěl jsem mít doma přehled. Vědět co hraje rádio, kdy jsem naposledy naměřil glukózu, jestli zásuvka v DJ studiu svítí nebo ne. Žádná hotová aplikace to neuměla přesně tak, jak jsem potřeboval. Tak jsem si ji napsal sám.

Z jednoho HTML souboru vznikl systém, který dnes nazývám KLADYXLAND — osobní digitální svět postavený od základů, jednou rukou, z mobilu, přesně podle mých představ.

Jádro systému

Panel — čtyřicet aplikací, jeden soubor.

Srdcem KLADYXLANDU je Panel.html — přes dvacet tisíc řádků kódu, čtyřicet samostatných aplikací v jednom souboru. Žádný framework, žádný build systém. Čistý HTML, CSS a JavaScript.

Infrastruktura

Mozky systému nikdy nespí.

Raspberry Pi 4B (hostname djsound, IP 192.168.0.50) běží 24/7 a pohání celé IoT jádro systému. Na něm běží osm systemd služeb:

tapo-py
Tapo P115/P100 bridge — python-kasa, polling 60 s, restart každé 4 h
irbridge
IR bridge — Samsung Radio + TV Sharp přes hub S08
tapobridge
Tuya IR bridge — ovládání zařízení přes Tuya protokol
plugbridge
Tuya plug bridge — chytré zásuvky přes Tuya cloud
pimonitor
Monitoring Pi4 — CPU, teplota, RAM → Firebase každou minutu
pitransfer
Transfer souborů mezi PC a Pi4 přes Firebase
prijatelister
Výpis přijatých souborů v /home/pi/nextsync/prijate/
uploadserver
Upload server — příjem souborů, port 8765

Pi4 se každý den v 22:20 automaticky vypne. Cron restartuje Tapo bridge v 6:05 ráno a každé 4 hodiny. Napájení Pi4 hlídá zásuvka Tapo P110 na IP 192.168.0.207.

PC Fujitsu E559 (IP 192.168.0.23) zajišťuje tři Windows služby: OBS Bridge, NextSync Server a Transfer Watcher. Startují automaticky po přihlášení do Windows.

Vše komunikuje přes Firebase Realtime Database — cloud, který slouží jako HTTPS most mezi lokální sítí a GitHub Pages panelem. Limit: 360 MB stažených dat denně, reset v 09:00.

Broadcasting

Zvuk od mikrofonu do světa.

Broadcast řetězec je přesně navržený pro maximální kvalitu hlasu při streamu. Každý přístroj v řetězci má svůj důvod a nastavení.

RØDE PodMic XLR
→ Art TubePre V2 předzesilovač · GAIN vysoký
→ DBX EQ3B ekvalizér · 80Hz HPF · MID +2dB · HIGH +1dB
→ DBX COMP16 kompresor · GR 3–6 dB při řeči
→ RØDECaster Duo Line-In · Level 20dB · Processing off
→ PreSonus Quantum ES4 zvuková karta USB-C
→ OBS Studio LoudMax · SPAN · Youlean · cíl −15 LUFS
→ Mixcloud Live stream do světa

OBS Bridge — Node.js skript running na PC — sleduje stav streamu a v reálném čase aktualizuje Firebase. Panel i veřejný web ihned zobrazí ON AIR. Stream lze spustit i zastavit přímo z panelu nebo webu.

Software monitoring: mvMeter2 PPM IIa BBC, SPAN, LoudMax (threshold −2.0 dB, output −1.0 dB), Youlean Loudness Meter Pro. Sluchátka Pioneer HDJ-X5 a Rode NTH-100 přes PreSonus HP4.

DJ Setup

Studio pro mixování.

Centrum DJ studia tvoří mixér Allen & Heath AR8c se čtyřmi stereo vstupy. Každý zdroj má své místo v signálovém toku.

Reloop RP 1000 gramofon → Mix 300s phono pre → AR8c kanál 1/2
DDJ 800 Pioneer DJ controller · XLR → AR8c kanál 3/4
CDJ 800 MK2 CD přehrávač → AR8c kanál 5/6
AR8c Main Out → PreSonus Quantum ES4 vstup 3/4

Monitorování zajišťuje PreSonus Monitor Station V2 — přepíná mezi reproduktory Sub 8 BT + Eris 4.5 BT (Main) a American Audio + Fun Generation RTA 31 (Cue). VU meter Nobsound L3-3 sleduje úrovně signálu ze sluchátkového zesilovače a mikrofon řetězce.

Mixcloud archivuje všechny sety. Každý stream přežije v historii — nic se neztrácí.

Retro Computing

ZX Spectrum Next — retro v síti.

ZX Spectrum Next je součástí KLADYXLANDU. Retro počítač žije v lokální síti na IP 192.168.0.124 — vedle Raspberry Pi a PC. Je to záměrný kontrast: nejmodernější Firebase cloud, a vedle toho osmibitový stroj z osmdesátých let.

Panel obsahuje dedikovanou appku ZX Next s deníkem vývoje — záznamy, co se na Nextu programuje, zkoušelo, testovalo. NextSync server na PC umí soubory přenášet přímo do Nextu a zpět. KLADYXLAND propojuje retro se současností.

Filozofie

Dělat věci sám má smysl.

Každý řádek kódu, který tady existuje, jsem napsal já. Jednou rukou, z mobilu, ve volném čase. Bez kurzu programování, bez týmu, bez investora.

KLADYXLAND je důkaz, že člověk nepotřebuje být profesionál, aby postavil něco fungujícího a smysluplného. Potřebuje jen trpělivost, zvědavost a ochotu nespoléhat na to, že někdo jiný vymyslí řešení za něj.

Systém roste každý den. Nové appky, nová automatizace, nové nápady. A dokud bude hrát hudba — bude žít i KLADYXLAND.
